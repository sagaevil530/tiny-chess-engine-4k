A compact alpha-beta chess engine in 4,096 bytes of Python for make.fun's tiny-chess-01 bounty: 0x88 board, negamax with quiescence, iterative deepening to a fixed node budget, material plus positional evaluation, and deterministic play through the make.fun env.

## Run it

```sh
MAKEFUN_ENV_URL=http://localhost:8080 python3 main.py
```
